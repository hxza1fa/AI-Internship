# Types of Learning

**NOTE: The distinction being made in these two types of learning is in the training section, or how the model learns, not how it makes predictions**

## 1. Supervised Learning

#### Model learns while being given the output
#### Maps inputs to outputs
#### Is used to make predictions 
#### `Example: Linear Regression`

## 2. Unsupervised Learning

#### Model learns while not being given outputs
#### Is used to classify data, label data, or make data efficent, not make predictions
#### `Example(s): K-means clustering, Principal Component Analysis (PCA), etc.`
