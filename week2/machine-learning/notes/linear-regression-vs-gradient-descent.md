# Linear Regression vs Gradient Descent

**NOTE: These are not two competing prediction models**

## 1. Linear Regression

#### Linear Regression predicts the output Y given outputs {x1, x2, ..., xn} connected to weights {w1, w2, ..., wn} and a bias b
#### It attempts to find the best fit line equation: `y = w1x1 + w2x2 ... + wnxn + b`

## 2. Gradient Descent

#### This is merely a method to find the values of the weights and bias because more often than not we don't know the starting values weights and bias
