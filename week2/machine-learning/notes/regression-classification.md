# Regression vs Classification

**NOTE: These are both supervised learning problems**

## 1. Regression

#### This is used for problems where we want to predict a real, continuous numerical value
#### `Example: Given some inputs, predict the price of this house`
## 2. Classification

#### This is used for problems where we want to predict a category or a class
#### `Example: Given some inputs, predict for these inputs whether the day will be sunny or rainy`
